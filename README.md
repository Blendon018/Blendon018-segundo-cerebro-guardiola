# 📖 Sobre o Projeto

Este repositório foi desenvolvido como parte de uma atividade acadêmica utilizando o **Google NotebookLM**.

O objetivo é reunir, organizar e consolidar conhecimentos sobre a metodologia de Pep Guardiola, utilizando livros, artigos científicos, entrevistas e vídeos como base para um estudo estruturado.

---

# 🎯 Objetivos

- Compreender a filosofia de jogo de Pep Guardiola.
- Estudar os princípios do Jogo de Posição.
- Analisar métodos de treinamento e liderança.
- Desenvolver habilidades de pesquisa com o NotebookLM.
- Produzir um guia de estudos reutilizável.
